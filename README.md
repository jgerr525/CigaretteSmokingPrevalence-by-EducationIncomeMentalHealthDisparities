# CigaretteSmokingPrevalence-by-EducationIncomeMentalHealthDisparities
This repository contains Python analysis and visualization scripts for a research project tracking trends in American adult smoking rates. The goal of this work is to see how smoking patterns have changed over a twelve-year period when looked at through the lens of three major life factors: education, income levels, and mental health distress.

Data was obtained from the Centers for Disease Control and Prevention.
